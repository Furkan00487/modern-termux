# Security Policy

## Supported Versions

Only the latest release and the current `master` branch receive security updates.

| Version | Supported |
| ------- | --------- |
| master  | :white_check_mark: |
| < latest | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Modern Termux, please report it responsibly and privately. **Do not create public issues, discussions, or pull requests for security flaws.**

### How to report

1. Open a confidential report via [GitHub Private Vulnerability Reporting](https://github.com/Furkan00487/modern-termux/security/advisories/new).
2. If the advisory tab is unavailable, contact via email at `furkan00487@users.noreply.github.com` with the subject `[SECURITY] Modern Termux Vulnerability`.

### What to include

- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal proof of concept (PoC) to reproduce the issue.
- Affected Android version, device architecture, and app build details.

We will review incoming reports promptly and coordinate a fix before any public disclosure.
